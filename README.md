## <a name="introduction">🤖 Introduction</a>

**InterVexia** is a high-performance interview simulation suite. Developed using **Next.js 14** for optimized server-side rendering and **Firebase** for hardened authentication. By integrating **Vapi’s low-latency voice agents**, the platform bridges the gap between static technical knowledge and real-world high-pressure communication.

The suite utilizes **Google Gemini** to generate context-aware technical roadmaps, providing candidates with instant, brutally honest feedback and detailed transcripts of their sessions.

---

## <a name="tech-stack">⚙️ Tech Stack</a>

* **Framework:** Next.js 14 (App Router)
* **Voice Engine:** Vapi AI (Real-time Voice Agents)
* **Intelligence:** Google Gemini Pro
* **Backend & Auth:** Firebase (Hardened Security Rules)
* **Styling:** Tailwind CSS & Framer Motion
* **Validation:** Zod (Type-safe Schemas)
* **UI Components:** shadcn/ui (Radix UI)

---

## <a name="features">🔋 Features</a>

👉 **Hardened Authentication**: Secure Sign-up and Identity Verification protocol handled by Firebase Auth.

👉 **Neural Interview Generation**: Dynamic role-based interview creation using Gemini AI and Vapi workflow integration.

👉 **Real-time Voice Intelligence**: Conduct full-voice interviews with AI agents that adapt to your technical level.

👉 **Automated Technical Feedback**: Receive a granular breakdown of Communication, Problem-solving, and Cultural fit with an 0-100 scoring system.

👉 **Developer Dashboard**: Manage secure session logs, track progress metrics, and retake interviews to improve latency in technical communication.

👉 **Cyber-Minimalist UI**: A sleek, high-contrast interface designed with a focus on technical clarity and responsiveness.
